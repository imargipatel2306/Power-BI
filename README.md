# Survey Data Analysis & Dashboard

## Project Overview

This project focuses on analyzing survey data to uncover trends, patterns, and insights about respondents' preferences and behaviors. An interactive Power BI dashboard is created to visually communicate the findings.


## Dataset Description

The dataset contains survey responses collected from participants, including various attributes such as demographics, preferences, and feedback metrics.
Key components of the dataset:
* Respondent demographics 
* Survey questions and responses
* Categorized feedback / ratings
* Aggregated breakdown of responses


## Objectives

* Analyze survey responses to identify trends and patterns
* Perform data cleaning and transformation
* Build an interactive dashboard for data visualization
* Provide actionable insights based on survey results


## Tools & Technologies

* Power BI


## Key Analysis Performed

* Data cleaning and formatting 
* Aggregation of survey responses
* Category-wise and demographic-wise analysis
* Creation of interactive visuals (charts, filters, slicers)
* Insight generation through dashboard storytelling


## Dashboard Features

* Interactive filters and slicers
* Visual breakdown of survey responses
* Comparative analysis across categories
* Easy-to-understand charts and KPIs


## Key Insights 

* Certain response categories showed higher engagement
* Trends varied across different respondent groups
* Key preferences and patterns were identified through visualization


## How to Use

* Download the `.pbix` file
* Open in Power BI Desktop
* Interact with filters and visuals to explore insights
